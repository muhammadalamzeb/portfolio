## Getting Started

### Prerequisites

Before running the project locally, make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/muhammadalamzeb/portfolio.git
```

2. Change into the project directory:

```bash
cd portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

The portfolio will run locally in your browser via the default React development server.

## Available Scripts

```bash
npm start
npm run build
npm test
npm run deploy
```

### Script Descriptions

- `npm start` — runs the app in development mode
- `npm run build` — creates a production-ready build
- `npm test` — runs the automated tests
- `npm run deploy` — publishes the build to GitHub Pages

## Deployment

This project is configured for deployment with GitHub Pages using the `gh-pages` package.

To deploy the application:

```bash
npm run deploy
```
